# skill-cleanup

Скилл для [Claude Code](https://claude.com/claude-code): показывает, какими из
накопившихся скиллов вы реально пользуетесь, и убирает лишние в **обратимый карантин** —
только те, что вы назвали сами.

---

## Зачем он нужен

Скиллы копятся: поставили пак ради одного, попробовали и забыли, получили дубль из
другого источника. Каждый лишний скилл занимает место в контексте своим описанием и
мешает модели выбрать нужный. Чистить вручную страшно — непонятно, что из этого
на самом деле работает.

Скилл решает это так:

- **Решаете вы, а не модель.** Скилл готовит таблицу и исполняет выбор. В карантин
  попадает только то, что вы назвали по номеру или имени и подтвердили словом «да» на
  показанный план.
- **Выбор точечный.** Единица — один скилл, а не пак: в одном паке бывает один живой
  скилл и двадцать мёртвых.
- **Ничего не стирается.** Папка переезжает в `~/.claude/skills-quarantine/<дата_время>/`,
  ведётся журнал, возврат — одной командой.

## Что показывает таблица

Скан читает историю сессий в `~/.claude/projects` и ничего не меняет. По каждому скиллу:

| Колонка | Что значит |
|---------|------------|
| Градация | активно — 3+ вызовов; редко — 1–2; косвенно — не вызывался, но его файлы читались или запускались; ни разу — никаких следов |
| Вызовы (модель / ты) | сколько раз скилл вызвала модель и сколько — вы через `/команду` |
| Файлы | в скольких сессиях открывались файлы скилла |
| Последний раз | дата последнего следа в истории |
| Ссылаются | кто упоминает скилл: `CLAUDE.md`, агенты, команды, другие скиллы |
| Дубль | скиллы с таким же описанием |
| Удаление | как убирается: папка, ссылка, файл — или не убирается точечно (плагин, claude.ai) |

Учитываются личные скиллы (`~/.claude/skills`), команды (`~/.claude/commands`), скиллы
плагинов и скиллы, синхронизированные с claude.ai. «Ни разу» значит «ни разу за окно
истории», которое указано в шапке отчёта.

## Установка

Нужен Python 3.9+; сторонних зависимостей нет.

### Как плагин

```
/plugin marketplace add melekhinartem19-hue/Cleanup-skill
/plugin install skill-cleanup@skill-cleanup
```

### Копированием папки

```bash
git clone https://github.com/melekhinartem19-hue/Cleanup-skill.git
cp -r Cleanup-skill/plugins/skill-cleanup/skills/skill-cleanup ~/.claude/skills/
```

Windows PowerShell:

```powershell
git clone https://github.com/melekhinartem19-hue/Cleanup-skill.git
Copy-Item -Recurse skill-cleanup\plugins\skill-cleanup\skills\skill-cleanup "$env:USERPROFILE\.claude\skills\"
```

## Как пользоваться

Скилл запускается только вручную — сам по себе он не срабатывает: `/skill-cleanup`
(при установке плагином — `/skill-cleanup:skill-cleanup`).

1. **Скан.** Строится отчёт `report.md` и `report.json`.
2. **Таблица.** Вы видите все скиллы с номерами и короткую сводку: паки, где
   используется меньшинство, скиллы «ни разу» со ссылками на них, дубли.
3. **План.** Вы называете номера, диапазоны или имена — например `9-15, 27, firecrawl-shop`.
   Скилл показывает точный список с предупреждениями («использовался», «на него
   ссылаются», «обновление пака может его вернуть») и ничего не переносит.
4. **Перенос.** Только после вашего «да» на этот план.
5. **Итог.** Сколько перенесено и где лежит карантин.

Вернуть скилл на место:

```bash
python ~/.claude/skills/skill-cleanup/scripts/quarantine.py list
python ~/.claude/skills/skill-cleanup/scripts/quarantine.py restore --pick "firecrawl-shop, tilda"
```

Карантин очищаете вы сами, когда убедитесь, что ничего не сломалось.

## Чего скилл не делает

- Не убирает ничего без явного выбора и подтверждения — даже скиллы «ни разу».
- Не удаляет файлы: только перенос, а для ссылок — снятие ссылки с сохранением оригинала.
- Не отключает отдельный скилл плагина — так нельзя; если в плагине не используется
  ничего, отключите плагин целиком через `/plugin`.
- Не трогает скиллы claude.ai (`anthropic-skills:*`) — они отключаются в настройках claude.ai.
- Не трогает ничего за пределами `~/.claude/skills` и `~/.claude/commands`.
- Не убирает сам себя.
