# Чистка скиллов

Убирать скиллы — решение пользователя. Скилл готовит таблицу и исполняет выбор; в **карантин** попадает только то, что пользователь назвал сам и подтвердил словом «да» на показанный план. Карантин обратим: папка переезжает в `~/.claude/skills-quarantine/`, ничего не стирается.

Выбор **точечный**: единица — один скилл, а не пак. В одном паке бывает один живой скилл и двадцать мёртвых.

## Шаги

Скопируй чек-лист в ответ и отмечай:

```
- [ ] 1. Скан
- [ ] 2. Таблица показана целиком → жду выбор
- [ ] 3. План показан → жду «да»
- [ ] 4. Перенос
- [ ] 5. Итог
```

### 1. Скан

```bash
python "${CLAUDE_SKILL_DIR}/scripts/scan.py"
```

Только читает. Пишет `report.md` и `report.json` в `~/.claude/skills-quarantine/`. Нет `python` — запасной вариант `py`. Готово, когда скрипт напечатал путь к таблице и итог по градациям.

### 2. Таблица

Прочитай `~/.claude/skills-quarantine/report.md` и покажи пользователю все таблицы как есть: каждая строка, номера без изменений. Номер строки — это то, чем пользователь выбирает.

Перед таблицами — короткая сводка из самого отчёта:

- паки, где используется меньшинство скиллов;
- скиллы «ни разу», у которых заполнено «Ссылаются»: они могут быть нужны агенту, CLAUDE.md или соседнему скиллу;
- дубли;
- сколько скиллов одновременно «ни разу», без ссылок и убираются точечно — самая безопасная группа.

Затем спроси, какие номера или имена убрать, и закончи ход. Готово, когда каждая строка отчёта есть в ответе и задан вопрос о выборе.

### 3. План

Передай в `--pick` ровно то, что назвал пользователь: номера, диапазоны, имена. Формулировку вроде «весь firecrawl, кроме поиска» разверни в номера по таблице сам.

```bash
python "${CLAUDE_SKILL_DIR}/scripts/quarantine.py" plan --pick "9-15, 27, firecrawl-shop"
```

Команда ничего не переносит: проверяет выбор и пишет `plan.json`. Покажи её вывод целиком — список, предупреждения, отказы. План берёт номера из отчёта шага 1; если скан запускался заново, сначала покажи новую таблицу.

Спроси: «Переношу в карантин эти N скиллов?» — и закончи ход. Готово, когда пользователь видит точный список с предупреждениями.

### 4. Перенос

Только после явного «да» на план из шага 3. Пользователь поменял список — вернись на шаг 3 и составь новый план.

```bash
python "${CLAUDE_SKILL_DIR}/scripts/quarantine.py" apply --approved
```

Флаги не меняй. Скрипт переносит по одному скиллу и ведёт журнал. Готово, когда по каждому скиллу плана есть строка результата; ошибки покажи дословно.

### 5. Итог

Сообщи: сколько перенесено, что карантин лежит в `~/.claude/skills-quarantine/<дата_время>/`, как вернуть (ниже). Убранные скиллы исчезнут из списка в новых сессиях. Очищает карантин пользователь сам, когда убедится, что ничего не сломалось.

## Что не убирается точечно

- **Скиллы плагинов** (в таблице «плагин»). Отдельный скилл плагина отключить нельзя: `skillOverrides` на них не действует. Если в плагине не используется ничего, предложи пользователю отключить плагин целиком командой `/plugin` в терминале.
- **Скиллы claude.ai** (`anthropic-skills:*`). Отключаются в настройках claude.ai.

## Возврат

```bash
python "${CLAUDE_SKILL_DIR}/scripts/quarantine.py" list
python "${CLAUDE_SKILL_DIR}/scripts/quarantine.py" restore --pick "firecrawl-shop, tilda"
```

`restore` возвращает скилл на прежнее место и отказывает, если оно уже занято.
